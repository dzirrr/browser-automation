# Browser Automation with Selenium

Otomatisasi pengisian Google Form menggunakan Selenium WebDriver dan Python.

## Fitur
- Pengisian form otomatis secara headless (tanpa GUI) maupun interaktif.
- Validasi input dinamis (teks, tanggal, dropdown, dan radio button).
- Mekanisme retry dan penanganan timeout.

## Persyaratan
- Python 3.8+
- Google Chrome browser terpasang

## Instalasi
```bash
pip install -r requirements.txt
```

## Penggunaan
```bash
python browser_automation.py
```
